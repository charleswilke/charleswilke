# Charles Wilke

Omaha, NE. I build things on the internet that arguably didn't need to exist, and then I ship them anyway.

Everything lives at **[charleswilke.com](https://charleswilke.com)**.

## What I make

### 🎮 Games

A hand-built Canvas arcade. No engine, no sprite sheets, no asset pipeline.

- **[TootsJam](https://charleswilke.com/tootsjam)**: hold-to-charge free throws with a real leaderboard
- **[SpaceToots](https://charleswilke.com/spacetoots)**: a synthwave shoot-em-up that fits in a single HTML file
- **Toots Quest**: a top-down adventure drawn entirely in code. Zero image assets, every wall and creature procedurally rendered. Currently in the workshop.

### ✍️ Writing

**[Exploring L.ai.bor](https://charleswilke.substack.com)**, essays on AI, creativity, and capitalism. Mostly about what happens to making things when the machines start making things too.

### 🎵 Music

Full albums built with AI collaborators: *Grief without Ritual*, *Junkyard Cabaret*, and the *Exploring L.ai.bor* mixtape (plus Side Two and the B-Sides, because every mixtape needs a flip).

### 🎭 Theater

Projection design for *Alice in Wonderland* and *Jersey Boys*.

## How I build

Vanilla HTML, CSS, and JavaScript. No frameworks, no build step, just files doing their job. A handful of Vercel serverless functions where the site genuinely needs a server. Canvas 2D and procedural drawing for the games, which is why they ship with no image assets at all.

That constraint is on purpose. It keeps things fast, keeps them legible, and keeps them mine.
